# Edtech-Instructor-Analysis
Data-driven analysis and machine learning for evaluating instructor effectiveness.

## Overview

This project analyzes instructor effectiveness using learner outcomes, engagement metrics, and feedback data. It applies data analysis and machine learning techniques to identify patterns and classify instructors into different effectiveness levels.

## Objectives

- Explore instructor and course-level performance data
- Analyze learner outcomes, engagement, and feedback
- Develop an Instructor Effectiveness Score
- Classify instructors into effectiveness tiers
- Identify the factors most associated with instructor effectiveness
- Provide insights that can support data-driven decision making

## Methodology

The project follows these steps:

1. Data loading and preprocessing
2. Exploratory Data Analysis (EDA)
3. Data quality and anomaly checks
4. Instructor-level aggregation
5. Feature normalization
6. Instructor Effectiveness Score calculation
7. Effectiveness tier classification
8. Machine learning model development
9. Model evaluation and feature importance analysis
10. Business and practical insights

## Effectiveness Score

The overall effectiveness score combines three major dimensions:

- **Learning Outcomes – 45%**
- **Learner Engagement – 30%**
- **Learner Feedback – 25%**

Instructors are subsequently categorized into Low, Medium, and High effectiveness tiers.

## Machine Learning

The project evaluates classification models including:

- Logistic Regression
- Random Forest Classifier

Model performance is evaluated using:

- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix

## Key Insights

The analysis examines how factors such as:

- Course completion
- Score improvement
- Quiz performance
- Dropout rate
- Watch time
- Assignment completion
- Forum participation
- Feedback score
- Feedback response rate

relate to overall instructor effectiveness.
